# Iris Flower Classification using K-Nearest Neighbors (KNN)

## Project Overview

This project demonstrates the classification of Iris flowers using the K-Nearest Neighbors (KNN) machine learning algorithm.

The model uses the Iris dataset provided by Scikit-learn to classify flowers into three species:
- Setosa
- Versicolor
- Virginica

## Implemented Steps

1. Load the Iris dataset.
2. Convert the dataset into a Pandas DataFrame.
3. Split the dataset into training and testing sets.
4. Apply feature scaling using StandardScaler.
5. Train a KNN classifier with k=3.
6. Predict flower species.
7. Evaluate model performance using accuracy, classification report, and confusion matrix.
